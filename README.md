## 📖 Overview

**Sentient-EduCore** is an applied computing framework designed to resolve the growing crisis of occupational burnout, administrative creep, and GenAI technostress in education. Rather than proposing detached wellness software, this project formalizes an **affective ergonomic interface** operating natively inside learning management environments (e.g., Moodle LMS).

The system integrates four modular pillars:
1. **Task-Agent:** Automated pedagogical scaffolding using Retrieval-Augmented Generation (RAG).
2. **Boundary-Guardian:** An intelligent digital firewall implementing statutory Right-to-Disconnect policies outside contracted working hours.
3. **Affective In-Situ Telemetry:** Non-invasive monitoring of nocturnal interaction patterns and typing friction to trigger real-time micro-CBT recovery prompts.
4. **Policy Dashboard:** Faculty-wide workload analytics protected by differential privacy and $k$-anonymity ($k \ge 10$).

* **Interactive Functional Sandbox (`app.py`):** Deployed on **Streamlit Cloud**, executing simulations of all four microservice subsystems in Python.
